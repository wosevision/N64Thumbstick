# Syntax Coloring Map For N64Thumbstick
#
# keywords.txt has up to four fields, separated by a single tab (not spaces):
#
#   KEYWORD  KEYWORD_TOKENTYPE  REFERENCE_LINK  RSYNTAXTEXTAREA_TOKENTYPE
#
# KEYWORD_TOKENTYPE:
#   KEYWORD1  datatypes   (editor.data_type.style)
#   KEYWORD2  functions   (editor.function.style)
#   KEYWORD3  structures  (editor.function.style)
#   LITERAL1  constants   (editor.reserved_word_2.style)
#   LITERAL2  (unused here; same theme slot as functions)
#
# REFERENCE_LINK opens Help > Find in Reference. Third-party libraries are not
# in the Arduino Language Reference, so that field is left empty.
#
# RSYNTAXTEXTAREA_TOKENTYPE overrides KEYWORD_TOKENTYPE on IDE 1.6.5 and newer.
# DATA_TYPE is the override equivalent of KEYWORD1. It is set on the datatype
# lines below so the four-field form is visible; the other lines use the
# two-field form.
#
# keywords.txt is global to the IDE, not scoped to sketches that include this
# library. Single-letter readings (x, y) and ordinary words (left, right, up,
# down, read) are intentionally omitted so they are not painted in every sketch.
